# Natural English Acquisition — Zero to B2

كتاب NLA كامل (600 صفحة) للناطقين بالعربية: من A0 إلى B2 — بدون ترجمة، بدون حفظ قواعد، بدون واجبات. كل صفحة تحمل: مشهدًا بصريًا، جملًا طبيعية، حوارًا واقعيًا مع الإيماءات، وسكربتًا صوتيًا جاهزًا لـ TTS.

## الملفات

| الملف | الوصف |

| `book/nla_book_full.json` | الكتاب كامل — 600 صفحة في ملف واحد |

| `book/level_A2.json` | المستوى A2 — الصفحات 101–220 (الموديولات 6–9) |

## نسخة الفيديو — Video Scripts (حلقات 10 دقائق)

`book/video/` يحوي **136 حلقة فيديو** (17 موديول × 8 حلقات × 10 دقائق) جاهزة للتصوير أو لأدوات توليد الفيديو:

- **الشخصيات:** المُعلّم (بوصفه مُربيًا) + الطفل — مشاهد حقيقية بأشياء حقيقية
- **المسار:** يبدأ من مرحلة الرضيع (استقبال صامت) وينمو حتى الطلاقة الكاملة (B2)
- **صفر مجهود:** لا يُطلب من الطفل أي إنتاج إطلاقًا — لا "كرر" ولا "دورك" — النمذجة فقط، والكلام يخرج وحده
- **البناء التراكمي:** كل حلقة تعرض سلّم الكلام التلقائي: كلمة ← كلمتان ← جملة كاملة (PLAY ← AHMED PLAY ← الجملة)
- **العربية للمُعلّم فقط:** المشاهد والحوار إنجليزي خالص، وملاحظات التوجيه بالعربية
- **بنية الحلقة (10 دقائق):** طقس افتتاح ← غمر المشهد ← اللعب الأساسي ← الحركة واللمس ← اللعب الحر ← استرجاع حلقات سابقة ← تهدئة ← طقس الختام
- **variation بديل** لكل حلقة لإعادة التصوير بمشهد مختلف بنفس الجمل

الملفات: `video_scripts_full.json` (الكل) أو `video_scripts_module_01.json` ... `_17.json` (لكل موديول).
